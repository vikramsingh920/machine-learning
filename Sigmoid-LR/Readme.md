# Sigmoid Logistic Regression

This project implements a **Sigmoid-based Logistic Regression model from scratch** using Python and NumPy.

## Data Used

I generated a **synthetic binary classification dataset** using Scikit-learn's `make_classification()`.

### Dataset Details

* **100 samples**
* **2 features**
* **1 informative feature**
* **0 redundant features**
* **2 classes**
* **1 cluster per class**
* `random_state = 41`
* `class_sep = 30`
* `hypercube = False`

The generated data was visualized using a scatter plot.

## What I Did

* Generated a synthetic binary classification dataset
* Visualized the data
* Implemented the **Sigmoid function** from scratch
* Implemented a Sigmoid-based classification model from scratch
* Added an intercept term
* Used a learning rate of `0.1`
* Trained the model for `1000` iterations
* Randomly selected samples during training
* Calculated the model weights and intercept
* Plotted the resulting decision boundary
