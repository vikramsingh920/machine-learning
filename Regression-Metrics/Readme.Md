# Regression Metrics

A beginner-level **Linear Regression** project using a student placement dataset.

## 📌 Overview

The project explores the relationship between **CGPA** and **placement package** and evaluates a Linear Regression model.

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## 📚 Topics Covered

* Data Exploration
* Data Visualization
* Train-Test Split
* Linear Regression
* Regression Metrics

* `Regression-mterics(1).ipynb` — Jupyter Notebook
* `placement (1).csv` — Dataset
